# Laieeq Ahmad — AI & Design Portfolio

Personal portfolio of Laieeq Ahmad, an Artificial Intelligence student and graphic designer. Built from the multi-profession portfolio framework using Next.js 16.3.4, React, and TypeScript.

## Run locally

Use Node.js 22 or newer (validated with Node.js 24.19.0).

```powershell
npm ci
npm run dev -- --hostname 127.0.0.1
```

Development preview: http://127.0.0.1:3000. For the production preview:

```powershell
npm run lint
npm run typecheck
npm run test:seo
npm run build
npm run start -- --hostname 127.0.0.1 --port 3002
```

In another terminal, run `npm run verify:preview` to check the production preview. This verification expects the default preview settings (no production domain and indexing disabled). Set `PREVIEW_URL` to test another local port.
