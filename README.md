# Multi-profession portfolio framework

A type-safe Next.js foundation for building distinct client portfolios without rebuilding the site for every profession.

Start with [CUSTOMIZATION.md](./CUSTOMIZATION.md). Most client work belongs in:

- `src/config/client.config.ts`
- `src/config/design.config.ts`
- `src/config/sections.config.ts`
- `src/data/*`
- `public/*`

Run locally:

```bash
npm run dev
```

Verify before delivery:

```bash
npm run lint
npm run build
```
